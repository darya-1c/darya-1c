
Загрузка файла Excel в 1С

📌 Что делает эта обработка
Загружает автомобили из файла Excel в справочник «Автомобили»

⚙️ Как работает
1. Пользователь открывает внешнюю обработку, в форме выбора "Файл Excel " выбирает соответствующий файл на компьютере, нажимает на кнопку «Загрузить файл» и автоматически в таблицу обработки подтягиваются данные о наименовании, стоимости, цвете и кузове авто из файла Excel.Также происходит соответствие по цвету, например, если цвет автомобиля желтый, то ячейка становится желтой
2. При нажатии на кнопку «Записать в справочник» обработка читает данные, проверяет на наличие такого автомобиля в справочнике «Автомобили»
3. Если есть - выдает соответствующее сообщение и данные в справочник не записывает, если нет — добавляет данный автомобиль в справочник, выдает соответствующее сообщение пользователю и показывает уведомление.
4. Также реализована ситуация, когда в 1 файле Excel могут быть одновременно автомобили, которые есть и которых нет в справочнике, тогда автомобили, которых нет записываются в справочник и пользователю выводится сообщение о количестве добавленных автомобилей
