
Старая методика контроля остатков в 1С

📌 Что делает эта обработка
Проверяет остатки на складах предприятия при проведении документа «Продажа Автомобилей» с помощью старой методики


⚙️ Как работает
1. Получаем запросом данные о наличии автомобилей, указанных в нашем документе 
2. В цикле перебираем наши автомобили и проверяем достаточно ли остатков 
3. Если автомобилей недостаточно - отменяем проведение документа  
4. Если автомобилей достаточно - проводим документ и записываем движения в регистр накопления «Количество Автомобилей»
