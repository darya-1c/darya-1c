
Новая методика контроля остатков в 1С

📌 Что делает эта обработка
Проверяет остатки на складах предприятия с помощью новой методики при проведении документа «Продажа Автомобилей»


⚙️ Как работает
1. Списываем указанные в документе «Продажа Автомобилей» автомобили
2. Проверяем образовались ли отрицательные остатки
3. Если образовались - отменяем проведение документа «Продажа Автомобилей»
